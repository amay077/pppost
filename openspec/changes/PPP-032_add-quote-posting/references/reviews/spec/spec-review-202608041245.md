## Summary

引用投稿の追加と Manual reply 廃止の proposal。各 SNS の実装方式（Bluesky の embed.record / recordWithMedia、Threads の quote_post_id、Misskey の renoteId）は公式サンプル・lexicon で裏付け済みであり、spec delta は既存 spec と一貫している。指摘は Minor 2 件（うち 1 件はリスク記録）のみ。

## Issues

### Issue 1: 排他要件の SHALL NOT 記述が規約に反する表記
- **Severity**: Minor
- **Location**: `specs/sns-posting/spec.md`（Requirement: リプライ元・引用元の選択）
- **Description**: 「システムは、リプライと引用を同時に指定できないようにしなければならない (SHALL NOT 同時指定)。」とあり、`(SHALL NOT 同時指定)` は OpenSpec の規約（`SHALL` / `MUST` / `SHALL NOT` の使用）に合致しない表記である。`SHALL NOT` の後にラベルを付ける形式は他に存在しない。
- **Suggestion**: 「システムは、リプライと引用を同時に指定してはならない (SHALL NOT)。」に修正し、「リプライ元を選択した場合は引用元の選択を解除し、引用元を選択した場合はリプライ元の選択を解除しなければならない (SHALL)。」の文はそのまま残す。

### Issue 2: Threads の quote_post_id の IMAGE / CAROUSEL 対応は実機検証が必要
- **Severity**: Minor
- **Location**: `specs/threads-posting/spec.md`（Requirement: Threads への引用投稿） / `proposal.md`（Open questions）
- **Description**: spec は「画像付きの場合も同様に、トップレベルのコンテナ（カルーセルの場合は親コンテナ）に quote_post_id を付与しなければならない (SHALL)」と MUST で規定しているが、Threads API の quote_post_id が IMAGE / CAROUSEL コンテナで有効であることは公式ドキュメントで直接確認できていない（公式サンプル fbsamples/threads_api ではコンテナ共通パラメータとして実装されている）。実機で不可だった場合、spec の修正が必要になる。
- **Suggestion**: 実装時のタスク 7.4（実機確認）で検証し、不可だった場合は spec の該当シナリオ（画像付きで引用する）を修正する。proposal.md の Open questions に既に記録済みであり、現時点での spec 変更は不要。
