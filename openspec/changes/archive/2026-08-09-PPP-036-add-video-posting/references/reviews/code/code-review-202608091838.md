## Major Issues
1. **Bluesky 動画投稿が Netlify 同期 Function の実行時間制約（10 秒）に収まらない見込み**（修正済み）
   - ポーリング予算が 6 回 × 2000ms = 12 秒で、動画取得・アップロード時間と合わさると確実に 10 秒を超える
   - 修正: ポーリングを最大 4 回 × 1000ms（計 4 秒）に縮小し、実行時間制約内に収める方針とした。実機テスト（tasks 8.3）で要検証

## Minor Issues
1. **動画投稿時も OGP 処理が実行される**（修正済み）
   - `embedOgp` に `if (embedVideo) return undefined;` を追加し、動画時は OGP 処理をスキップ
2. **動画添付中の画像追加は「拒否」ではなく「動画の解除」**（修正済み）
   - `ImagePreview` に `disabled` プロパティを追加し、動画添付中は画像追加ボタン・ペーストを無効化（仕様シナリオ「画像の追加は受け付けられない」に一致）
3. **未知拡張子の動画が `pppost/video/` 配下に保存されない**（修正済み）
   - `MIME_BY_EXT` に無い拡張子は 400 で拒否するように変更
4. **duration が NaN の場合に上限チェックをすり抜ける可能性**（修正済み）
   - `Number.isFinite(video.duration)` を確認し、非有限なら読み込み失敗として拒否
5. **タスク未完了項目が残る**（対応: 手動テスト 8.3/8.4/8.5 は E2E フェーズで扱う）
