## Issues

### Issue 1: タイトル取得失敗時に一般的なタイトル取得へフォールスルーし本文が変換され得る
- **Severity**: Major
- **Location**: `frontend/src/lib/MainContent.svelte:352`
- **Description**: `if (!swarmHandled && !youtubeHandled && queryValueUsed)` により、YouTube タイトル取得に失敗すると `youtubeHandled` が false のまま一般タイトル取得へフォールスルーする。本文が YouTube URL のみの場合は `extractUrlOnly` が URL を返し、`fetchTitleForUrl` が成功すると本文が `{タイトル} - {URL}` に変換される。これは spec の Scenario「Title fetch failure」の THEN「本文を変換しない（元のテキストのまま維持する）」と「Priority over generic title fetch」の「URL のみの場合の一般的なタイトル取得処理をスキップする」（WHEN に成功条件なし）に反する。design.md の Risks 節「失敗時は本文を変換しない（現状維持）ことでフォールバック」の記述とも整合しない。
- **Spec Reference**: specs/PPP-002-url-title-expansion/spec.md「Title fetch failure」「Priority over generic title fetch」
- **Suggestion**: YouTube URL を検出した場合は（タイトル取得の成否に関わらず）一般タイトル取得をスキップする（例: `let youtubeHandled = !!youtubeUrl` としておく）。またはフォールバックが意図なら、spec のシナリオ文言を「取得成功時のみスキップ」に修正して仕様と実装を一致させる。
