## Minor Issues

1. **複数 YouTube URL 混在時の挙動が spec 未定義**
   - design.md の Non-Goals に「複数 URL 混在時の個別整形」の除外はあるが、複数の YouTube URL が本文に含まれる場合の展開対象（最初の URL? 全 URL?）と本文全体置換の結果（タイトルはどれのものか）が spec から一意に定まらない。実装の一意性のため、例として「最初に検出した URL を展開し本文全体を置換する」旨をシナリオに明記するか、Non-Goals の範囲であることを spec で明示すると良い。
2. **日本語文末記号の除外が spec に未記載**
   - tasks.md 2.1 に「日本語文末記号は除外」とあるが、spec の検出シナリオ（`Short URL detection` / `Full URL detection`）には記載がない。検出仕様は spec が正となるため、「本文中に含まれる」検出時の文末記号（`。` 等）の扱いをシナリオに明記すると、実装の正解が spec 単体で確定する。既存 Swarm 検出にも同様の記載がないため粒度は既存に合わせてもよいが、推奨事項として挙げる。
