## Major Issues

1. **動画投稿とリプライ・引用の関係が未定義**
   - 対象: `specs/video-posting/spec.md` 全体、`specs/sns-posting/spec.md`（delta）、既存 `openspec/specs/sns-posting/spec.md:53-86`
   - 既存の「Bluesky への引用投稿」は `app.bsky.embed.recordWithMedia` の `media` に画像（`app.bsky.embed.images`）を指定すると定めるが、動画添付時（`media` に `embed.video`）の扱いが video-posting にも sns-posting delta にも無い。Threads（`quote_post_id`/`reply_to_id` + `media_type=VIDEO` コンテナ）・Misskey（`renoteId`/`replyId` + 動画 `fileIds`）も同様に未定義。動画+引用（またはリプライ）を選択した場合の挙動が決まらない
   - 修正方針: Non-Goals に「動画と引用/リプライの併用は対象外」を明記し、video-posting に「動画添付時は引用・リプライ指定を無効化する」要件を追加

2. **R2 アップロード失敗時の扱いが未定義**
   - 対象: `specs/video-posting/spec.md`（動画投稿失敗時のエラー通知）
   - エラー通知要件は「失敗した SNS 名をエラー一覧へ追加」と定めるが、R2 の署名付き URL 発行失敗・PUT 失敗はどの SNS にも到達していないため、どの SNS 名をエラー一覧に追加するのか不明。全 SNS 投稿を中断して共通エラーとして通知するのかが決まらない
   - 修正方針: 同要件に「R2 アップロード失敗時は全 SNS への投稿を試行せず、共通エラーとして通知する」旨を明記

3. **共有ボタンの無効化条件と動画共有の矛盾（web-share spec 未更新）**
   - 対象: `specs/video-posting/spec.md`（共有） vs 既存 `openspec/specs/web-share/spec.md:35-49`
   - web-share の「共有内容が空のときの無効化」は `text.length <= 0 && images.length <= 0` で動画を考慮していない。動画のみ添付（本文なし）では共有ボタンが無効になり、video-posting の「動画が添付されている状態で共有ボタンが押されたとき…動画を files に含めて共有しなければならない」と矛盾する。proposal.md の Affected specs にも `web-share` が無い
   - 修正方針: web-share の delta（MODIFIED）を追加し、無効化条件に動画を含める。proposal の Affected specs に web-share を追加

## Minor Issues

1. **併用禁止要件の二重定義**
   - 対象: `specs/video-posting/spec.md`（動画の選択とプレビュー）と `specs/sns-posting/spec.md`
   - 「動画と画像の併用禁止」が video-posting（UI レベル）と sns-posting（投稿全般）の両方に ADDED されており重複。sns-posting 側は video-posting への参照を設けて最小限に止めるとよい

2. **Bluesky の実再生時間制限と 5 分チェックの乖離**
   - 対象: `specs/video-posting/spec.md`（許容上限チェック）、proposal.md（Non-Goals）
   - フロントの 5 分（300 秒）チェックは全 SNS 共通上限だが、Bluesky の実制限は 3 分以下である可能性が proposal の Non-Goals で認められている。spec に「Bluesky 固有の再生時間制限を確認し、必要なら適用する」旨を記載すると実装・検証が確実になる

3. **Bluesky の alt テキストの入力元が不明**
   - 対象: `specs/video-posting/spec.md`（Bluesky への動画投稿）
   - alt テキストを指定すると書かれているが、入力 UI の要件（alt 入力欄の有無・空文字の扱い）が無い。画像と同様の alt 入力 UI を追加するか、固定の自動生成とするかを明記すべき

4. **Threads ゴースト投稿時の動画の扱いが未定義**
   - 対象: 既存 `openspec/specs/threads-posting/spec.md`（ゴースト投稿）
   - 既存要件は `is_ghost_post=true` のとき「添付画像を無視し `media_type=TEXT`」と定めるが、動画が添付された場合の扱いが無い。動画も同様に無視して TEXT にする旨を明記する

5. **tasks.md:34（5.3）の実装方針が揺れている**
   - 「画像を無視して動画のみを投稿する（または 400 を返す）」と二択になっている。フロントで排他制御する前提ならバックエンドは 400 拒否に固定し、spec（併用禁止）との整合を取るべき

6. **1 つの Scenario に GIVEN が 2 連続で記述されている**
   - 対象: `specs/video-posting/spec.md`（「動画と画像の併用はできない」）
   - 同一 Scenario 内に GIVEN/WHEN/THEN の連鎖が 2 組あり、2 つの Scenario に分割するのが望ましい
