## Minor Issues

1. **投稿ボタンの無効化条件と「動画のみ投稿」の扱いが未定義**
   - web-share delta は「無効化条件は既存の投稿ボタンと同一」と要件化するが、実際の投稿ボタンは本文必須（`text.length <= 0` で無効）で共有ボタンとは元々条件が異なる。動画のみ（本文なし）投稿を許可するのかが明記されていない
   - 修正方針: Non-Goals に「本文なしの動画のみ投稿は対象外」を追加

2. **動画+リプライ・引用をバックエンドが受信した場合の拒否が未定義**
   - 排他制御はフロントのみ（tasks 4.4）で、バックエンド側の拒否要件がない
   - 修正方針: 「動画投稿時のリプライ・引用の禁止」に、バックエンドが video とリプライ元・引用元を同時受信した場合は 400 で拒否する旨を明記し、tasks に追加

3. **「動画添付中は引用元を選択できない」Scenario が存在しない**
   - 要件文には「リプライ元または引用元」とあるが、Scenario はリプライ元のみ。引用元版の Scenario を追加する

4. **tasks 4.1「base64 経由の廃止」の表現が既存フローへの変更を暗示**
   - 既存の画像アップロードは base64 方式。spec は動画限定だが、tasks の書き方は画像の base64 廃止（Breaking changes）にも読める
   - 修正方針: 「動画アップロードでは base64 を介さず File/Blob を直接 PUT できるようにする（画像の既存フローは変更しない）」等に限定

5. **Bluesky の日次アップロード上限（`getUploadLimits`）超過時の扱いが spec 未記載**
   - `uploadVideo` 自体の失敗は「動画投稿失敗時のエラー通知」で吸収可能だが、明記すると確実。また tasks 9.2 に web-share spec への反映確認が無い
