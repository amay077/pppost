# Implementation Tasks

## 1. 本文エリアのドロップ対応（MainContent.svelte）

- [ ] 1.1 本文エリア（Message ラベル + textarea を含むブロック）に `dragover` / `dragleave` / `drop` ハンドラを実装する
- [ ] 1.2 ドラッグ中にハイライト表示する状態変数とスタイルを追加する
- [ ] 1.3 `drop` 時に `DataTransfer` から `File` リストを取得し、`image/*` と `video/*` に振り分ける（画像と動画が混在する場合は動画のみを添付し、画像を追加しない。複数の動画が含まれる場合は先頭のみを使用する）
- [ ] 1.4 画像ファイルは既存の画像追加ロジックと同一の `ImageData` 生成（`loadImageAsDataURL`）で `images` へ追加する（複数可）
- [ ] 1.5 動画ファイルは既存の `validateVideo`（100MB・3 分・メタデータ読み取り）で検証し、成功時のみ `setVideoFile` で 1 本添付する
- [ ] 1.6 動画ドロップ時は既存の動画ボタン選択時と同様に画像・リプライ元・引用元を解除する
- [ ] 1.7 画像ドロップ時に動画が添付済みなら動画を解除する（既存の排他ルールに従う）
- [ ] 1.8 画像・動画以外のファイルは無視する
- [ ] 1.9 ドロップハンドラでブラウザ標準のファイルオープンを preventDefault で抑止する
