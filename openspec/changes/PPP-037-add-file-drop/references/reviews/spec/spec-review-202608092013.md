## Summary

本文エリアへのファイル ドラッグ&ドロップ追加の proposal をレビューした。`openspec validate --strict` はパスし、フォーマット・要件間の整合・実コード（`MainContent.svelte` の排他ロジック・`validateVideo`）との整合・タスク計画はおおむね妥当。指摘はすべて Minor で、混在ドロップの仕様未定義・SHALL NOT の用法不正確・エラーケースのシナリオ欠落などが残るが、approval を妨げる重大な問題はない。

## Issues

### Issue 1: 「エラー表示は必須ではない」の SHALL NOT 用法が不正確
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: サポート外ファイルの無視）
- **Description**: 「エラー表示は必須ではない (SHALL NOT)」という記述は、「〜してはならない」という禁止（SHALL NOT）と「必須ではない」という許容・任意を意味が取り違えている。SHALL NOT は仕様上「禁止」を表すため、意図が「エラーを表示してもよい（任意）」なのか「エラーを表示してはならない（禁止）」なのかが判読不能。後者が意図なら文言を「エラーを表示してはならない (SHALL NOT)」とし、前者なら SHOULD を避けた表現（例:「エラー表示の有無は実装に委ねるものとする」）にする必要がある。
- **Suggestion**: 意図を明確にし、SHALL NOT を禁止文に対してのみ使用するよう修正する。

### Issue 2: 画像と動画が混在する複数ファイル ドロップの挙動が仕様未定義
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: 本文エリアへの画像ドロップ / 動画ドロップ）
- **Description**: 複数ファイルを同時にドロップし、`image/*` と `video/*` が混在する場合の挙動が仕様に記載されていない。画像を先に追加してから動画を設定する実装だと画像が解除されて動画のみ残り、動画を検証してから画像を追加する実装だと動画が解除されて画像のみ残るなど、実装順序で結果が変わり得る。要件文・シナリオとも単一種類のみを前提としており、実装者の裁量に委ねられている。
- **Suggestion**: 混在ドロップ時の優先順位（例:「動画が優先され、画像・リプライ元・引用元が解除される」「混在時は動画のみを添付する」等）を 1 シナリオ追加して明文化する。

### Issue 3: 動画の読み込み不可（メタデータ取得失敗）ケースのシナリオが欠落
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: 本文エリアへの動画ドロップ）
- **Description**: 要件文は「100MB 以内・3 分以内・再生時間の取得」を含み `video-posting` 準拠としているが、シナリオは「100MB 超」「3 分超」のみで、`video-posting` の「再生時間を取得できない動画」に対応するドロップ時のシナリオがない。実装では `validateVideo` が「動画を読み込めません。別のファイルを選択してください」を返すケースであり、エラーケースの網羅性として不足。
- **Suggestion**: 「再生時間を取得できない動画をドロップする」シナリオを追加し、添付されずエラーが通知されることを明記する。

### Issue 4: ドロップ完了時のハイライト解除シナリオが欠落
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: ドラッグ中の視覚フィードバック）
- **Description**: 要件文では「ドロップが完了した場合、ハイライト表示を解除しなければならない」とあるが、シナリオは「ドラッグ離脱で解除」のみで、ドロップ完了による解除のシナリオがない。要件文からは検証可能だが、シナリオとしての網羅性を高めるのが望ましい。
- **Suggestion**: 「ドロップ完了でハイライトが解除される」シナリオを追加する。

### Issue 5: tasks.md の実機確認に「非対応ファイルの無視」が明記されていない
- **Severity**: Minor
- **Location**: `tasks.md`（タスク 2.3）
- **Description**: タスク 2.3 の確認項目は「画像ドロップ・動画ドロップ・排他動作・ドラッグ中ハイライト」で、Requirement「サポート外ファイルの無視」に対応する確認（例: PDF をドロップして無視されること）が明記されていない。
- **Suggestion**: タスク 2.3 に「画像・動画以外のファイルが無視されること」を追加する。
