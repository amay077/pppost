## Issues

### Issue 1: 要件 1 の「画像以外のファイル種別は、動画として扱ってはならない」が要件 2 と矛盾する文言
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: 本文エリアへの画像ドロップ、11 行目）
- **Description**: 「画像以外のファイル種別は、動画として扱ってはならない (SHALL NOT)」は、文字どおり読むと `video/*` を動画として添付する要件 2 の冒頭文（「動画ファイル（`video/*`）を…添付しなければならない (SHALL)」）および混在ドロップ・動画ドロップの各シナリオと矛盾する。想定意図は「画像以外のファイル種別を画像として扱ってはならない」（PDF 等を画像に誤分類しない）か、分類規則（`image/*` → 画像・`video/*` → 動画・それ以外 → 無視）の言い換えと推測されるが、現文言では判読不能。
- **Suggestion**: 「画像以外のファイル種別は、画像として扱ってはならない (SHALL NOT)」に修正するか、あるいは要件 3（サポート外ファイルの無視）と重複するため削除する。

### Issue 2: 混在ドロップの動画優先が tasks.md の実装手順に明示されていない
- **Severity**: Minor
- **Location**: `tasks.md`（タスク 1.3〜1.7）
- **Description**: 要件 2 で「混在時は動画を優先し画像を添付してはならない (SHALL NOT)」と仕様化されたが、タスク 1.3（`image/*` と `video/*` に振り分け）〜 1.7（画像追加時の動画解除）には混在時の優先順位が明記されていない。実装順序によって結果が変わり得る（画像を先に追加してから動画を検証・`setVideoFile` する実装なら動画優先になるが、動画を検証してから画像を追加する実装では `MainContent.svelte:111-113` の `$: if (images.length > 0 && videoFile != null)` が動画を解除し画像優先になる）。
- **Suggestion**: タスク 1.3 または 1.5 に「画像と動画が混在する場合は動画のみを添付し、画像を追加しない」旨を明記する。

### Issue 3: proposal.md の What Changes に混在ドロップの動画優先が未反映
- **Severity**: Minor
- **Location**: `proposal.md`（What Changes、12 行目）
- **Description**: What Changes は排他ルール（動画ドロップで画像・リプライ元・引用元が解除 / 画像ドロップで動画が解除）のみを記載し、iteration 2 で spec に追加された混在ドロップの動画優先（「動画を優先して添付し、画像は添付しない」）が含まれていない。spec が proposal の 5 項目より広い仕様を持ち、proposal と spec の対応にずれがある。
- **Suggestion**: What Changes に「画像と動画が混在するドロップでは動画を優先して添付し、画像は無視する」を 1 項目追加する。

### Issue 4: 複数動画ドロップ時に添付する動画の選定規則が未定義
- **Severity**: Minor
- **Location**: `specs/file-drop/spec.md`（Requirement: 本文エリアへの動画ドロップ）
- **Description**: 要件 2 は「1 本のみ添付」を定めるが、動画ファイルが複数ドロップされた場合にどの動画を添付するか（先頭ファイル等）が定義されていない。単数ドロップを前提にしたシナリオしかなく、複数動画のシナリオがない。
- **Suggestion**: 「先頭の動画ファイルを添付する」等の選定規則を要件文に追記する（低優先）。
