# file-drop Specification

## Overview

本文（Message）エリアへのファイル ドラッグ&ドロップによる画像・動画の添付に関する仕様。ドロップによる添付は既存の添付経路（ボタン選択・クリップボード貼り付け）と同一の添付状態を操作し、画像と動画の排他（`sns-posting`）・動画の許容上限チェック（`video-posting`）に従う。

## ADDED Requirements

### Requirement: 本文エリアへの画像ドロップ（Drop image files onto message area）

システムは、本文エリアにドロップされた画像ファイル（`image/*`）を、既存の画像添付（`ImageData` の追加）と同じ状態として複数枚まとめて添付しなければならない (SHALL)。ドロップ時に動画が添付済みである場合、システムは `sns-posting` の排他ルールに従って動画を解除してから画像を添付しなければならない (SHALL)。画像以外のファイル種別は、画像として扱ってはならない (SHALL NOT)。

#### Scenario: 画像ファイルをドロップして添付する（Drop image files to attach）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ画像ファイル（1 枚または複数枚）をドロップする
- **THEN** ドロップした画像が画像プレビューへ追加され、投稿時に添付される

#### Scenario: 動画添付済みの状態で画像をドロップする（Images dropped while a video is attached）

- **GIVEN** ユーザーが動画を添付済みである
- **WHEN** 本文エリアへ画像ファイルをドロップする
- **THEN** 動画が解除され、ドロップした画像が添付される

### Requirement: 本文エリアへの動画ドロップ（Drop video files onto message area）

システムは、本文エリアにドロップされた動画ファイル（`video/*`）を、既存の動画選択（ボタン選択）と同じ振る舞いで 1 本のみ添付しなければならない (SHALL)。複数の動画がドロップされた場合、システムは先頭の動画ファイルのみを添付しなければならない (SHALL)。動画ドロップ時も `video-posting` の許容上限チェック（100MB 以内・3 分以内・再生時間の取得）を適用し、上限を超える動画は添付せずユーザーにエラーを通知しなければならない (SHALL)。ドロップ時に画像が添付済みである場合、システムは `sns-posting` の排他ルールに従って画像・リプライ元・引用元を解除してから動画を添付しなければならない (SHALL)。動画と画像が混在する複数ファイルのドロップでは、動画を優先して添付し、画像は添付してはならない (SHALL NOT)。

#### Scenario: 動画ファイルをドロップして添付する（Drop a video file to attach）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ許容上限内の動画ファイルをドロップする
- **THEN** 動画が `<video>` 要素でプレビュー表示され、投稿時に添付される

#### Scenario: 複数の動画をドロップする（Drop multiple video files）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ複数の動画ファイルをドロップする
- **THEN** 先頭の動画ファイルのみが添付され、2 本目以降の動画は添付されない

#### Scenario: 上限を超える動画をドロップする（Drop a video that exceeds limits）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ 100MB を超える、または再生時間 3 分を超える動画ファイルをドロップする
- **THEN** 動画は添付されず、既存の動画バリデーションと同じエラーがユーザーに通知される

#### Scenario: 再生時間を取得できない動画をドロップする（Drop a video whose metadata cannot be read）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ再生時間を取得できない動画ファイルをドロップする
- **THEN** 動画は添付されず、動画を読み込めない旨のエラーがユーザーに通知される

#### Scenario: 画像添付済みの状態で動画をドロップする（A video dropped while images are attached）

- **GIVEN** ユーザーが画像を添付済みである
- **WHEN** 本文エリアへ動画ファイルをドロップする
- **THEN** 画像・リプライ元・引用元が解除され、ドロップした動画が添付される

#### Scenario: 画像と動画が混在するファイルをドロップする（Drop a mix of images and videos）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ画像と動画が混在する複数ファイルをドロップする
- **THEN** 動画のみが添付され、画像は無視される
- **AND** 添付済みの画像・リプライ元・引用元があれば解除される

### Requirement: サポート外ファイルの無視（Ignore unsupported files）

システムは、画像・動画以外のファイル（例: PDF）が本文エリアにドロップされた場合、そのファイルを添付してはならず (SHALL NOT)、無視しなければならない (SHALL)。

#### Scenario: 画像・動画以外のファイルをドロップする（Drop an unsupported file）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** 本文エリアへ画像・動画以外のファイル（例: PDF）をドロップする
- **THEN** ファイルは添付されず、既存の添付状態は変化しない

### Requirement: ドラッグ中の視覚フィードバック（Visual feedback while dragging）

システムは、ファイルが本文エリアの上をドラッグされている間、ドロップ可能であることを示す視覚フィードバック（ハイライト表示）を表示しなければならない (SHALL)。ドラッグが本文エリアから離れた場合、またはドロップが完了した場合、ハイライト表示を解除しなければならない (SHALL)。

#### Scenario: ドラッグ中にハイライトが表示される（Highlight shown while dragging）

- **GIVEN** ユーザーが投稿画面を開いている
- **WHEN** ファイルをドラッグして本文エリア上に重ねる
- **THEN** 本文エリアがハイライトされ、ドロップ可能であることが視覚的に示される

#### Scenario: ドラッグ離脱でハイライトが解除される（Highlight cleared after drag leaves）

- **GIVEN** 本文エリアがドラッグ中のハイライト表示になっている
- **WHEN** ファイルが本文エリアから離れる
- **THEN** ハイライト表示が解除される

#### Scenario: ドロップ完了でハイライトが解除される（Highlight cleared after drop）

- **GIVEN** 本文エリアがドラッグ中のハイライト表示になっている
- **WHEN** ファイルを本文エリアにドロップする
- **THEN** ハイライト表示が解除される
